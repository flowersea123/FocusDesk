ESP32 配网

设备连接状态 · 在设备配网页确认

  1. 将电子纸接入与电脑互通的 2.4 GHz Wi-Fi。
  2. 按设备的 RST 键，连接 FocusDesk-Setup 热点，打开 http://192.168.4.1。
  3. 填写上方的地址。已有 Wi-Fi 配置时，可用 Save Hub only；首次连接时填写 Wi-Fi 名称和密码。
  4. 确认设备显示新的 Saved Hub address，再回工作台修改任务，检查电子纸是否刷新。
早期联网固件

使用 Arduino IDE 将地址填入本地 private_config.h 的 FOCUSDESK_API_URL，然后验证并上传。

无法连接时
  • 确认服务窗口未关闭，电脑未休眠，设备与电脑网络互通。
  • 在同一局域网的另一台设备上打开对应的 Dashboard 地址，先检查电脑服务是否可访问。
  • Windows 提示是否允许网络访问时，按实际使用场景允许专用网络。不要关闭整个防火墙。
  • 来宾 Wi-Fi、路由器客户端隔离、VPN 或企业网络策略可能阻止设备互访。
