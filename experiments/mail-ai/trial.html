配置 Microsoft 应用
  1. 在 Microsoft Entra 中打开应用注册，选择「新注册」，名称填写 FocusDesk。账户类型选择「仅限个人 Microsoft 账户」，或选择同时支持组织和个人 Microsoft 账户的选项。
  2. 在「身份验证」添加「移动和桌面应用程序」平台，填写自定义重定向 URI
    http://localhost:5184/auth/callback
  3. 在「API 权限」添加 Microsoft Graph 的委托权限 Mail.Read。从应用「概述」复制应用程序（客户端）ID，填入上方。
