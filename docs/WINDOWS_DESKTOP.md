# FocusDesk Windows 安装版

M1 安装版适用于 Windows 10/11 x64。安装包内含固定的 Node.js 24 运行时，用户不需要安装 Node、npm、Python 或其他开发工具，也不需要打开终端。

## 安装与使用

1. 运行 `FocusDesk-Setup.exe`，按引导安装。默认仅安装到当前 Windows 用户的应用目录。
2. 从桌面或开始菜单打开 FocusDesk。服务就绪后，默认浏览器自动打开 Dashboard。
3. 任务管理、保存和固定 25 分钟专注使用方式与原版一致。
4. 通知区域的 FocusDesk 托盘菜单可打开 Dashboard、设备连接、日志目录、导入旧任务和网络诊断。
5. 关闭浏览器后，FocusDesk 和电子纸同步继续运行。需要停止时，在托盘菜单选择“退出 FocusDesk”。再次点击快捷方式会复用已经运行的实例。

安装版暂不提供云服务、账号、自动配网、自动发现或设备配对，也不设置开机自启或系统后台服务。安装和本地使用不需要互联网；设备与电脑仍需可以互访的局域网。

## 用户数据

程序与内置运行时安装到 `%LOCALAPPDATA%\Programs\FocusDesk`。所有可变数据放在独立的 `%LOCALAPPDATA%\FocusDesk`：

- `data\tasks.json`：任务和活动专注，沿用原 JSON 格式和原子保存。
- `config\focusdesk.config.json`：监听地址与端口，默认 `0.0.0.0:8787`。
- `logs`：应用和启动器日志，每种日志限制单文件约 128 KiB，最多三个归档。
- `backups`：旧数据导入前保存的原文件备份。

首次运行且任务文件不存在时创建空任务；已有文件不会被重置为演示数据。升级只更新程序文件，默认卸载也保留这些用户数据。重新安装后可以继续使用。手动删除用户数据属于独立操作，请先备份。

## 导入旧版 FocusDesk-LAN 数据

1. 在旧版程序中完成保存并退出旧服务。
2. 在新版托盘菜单选择“导入旧任务…”，选择旧服务目录里的 `backend\data\tasks.json`。
3. 文件通过格式、容量和设备数据约束检查后，程序提示确认替换。取消不会导入。
4. 确认后先备份当前任务文件，再原子替换；旧版原文件保持不变。
5. 刷新 Dashboard 查看导入结果。任务 ID、顺序、完成状态、文件日期、时区和专注结束时间均保留；已经到期的专注依原规则自然结束。

导入期间如果任务在网页中被修改，版本保护会拒绝覆盖，请核对后重新选择文件。失败时不会自动改用演示任务。导入会替换整个任务文件，不自动合并两份任务。备份可能包含个人任务，请按个人数据保管。

## ESP32 与网络

M1使用现有设备HTTP/JSON协议、局域网只读和本机编辑权限。设备预刷 [统一固件](../firmware/focusdesk_device/README.md) 后，通过手机连接设备热点并打开 `http://192.168.4.1`，填写Wi-Fi和本电脑“设备连接”页面提供的Hub地址，保存后自动恢复。换电脑、Wi-Fi或IP/端口时，按设备RST重新打开页面修改。原 `focusdesk_live` 示例仍使用编译期私有配置，采用该旧入口时需修改并重新上传。安装包不包含Wi-Fi密码。

托盘“设备连接”展示当前局域网地址。Windows 提示网络权限时，按实际使用场景允许 FocusDesk 内置运行时访问专用网络。托盘“检查专用网络访问”只读检查当前网络及应用允许规则，不修改规则，不关闭防火墙。诊断是提示，不能代替另一台设备的实际访问检查；企业策略、来宾 Wi-Fi 和路由器隔离可能阻止通信。

## 错误处理

- 端口被占用：先检查旧版 FocusDesk 是否仍在运行；不会终止占用端口的未知程序。需要时可在用户配置中调整端口后重启，并同步更新设备地址。
- 数据已被使用：退出使用同一份任务文件的另一个实例，再启动。
- 数据或配置无法读取：原文件保留，检查备份和日志；不要随意删除唯一数据副本。
- 启动超时或运行中异常退出：程序提示错误，回收本实例启动的子进程，日志只记录安全事件码和运行信息。
- 无法打开浏览器：检查系统默认浏览器，或从托盘再次打开 Dashboard。

当前发行包若未进行代码签名，Windows SmartScreen 可能显示发布者提示。仅从你信任的来源获取安装包并核对随附哈希。升级/卸载会先请求退出已运行的安装版，停止失败时应中止，不强制删除正在使用的程序。
