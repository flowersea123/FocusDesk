## 最终演示脚本

1. 运行 B 指定的服务，加载已标识的合成今日任务；Web 与 ESP32 指向同一个局域网服务。
2. 对照 Backend revision、Web 任务顺序/状态、串口已显示版本和电子纸实物；截图预览不能代替实物。
3. 经 B 的演示入口切换至第二份内容，确认 revision 改变，测量网页与真机更新延迟并记录实际值；性能目标在获知面板刷新时长后确定。
4. 重复读取同版本，确认不触发不必要刷屏；以合法空列表确认旧任务被替换为无任务状态。
5. 断开服务/网络，确认网页报告读取失败，设备不发起无效刷新并保留最后有效内容；恢复后可取新版本。另测显示失败：实际屏幕标记未知，不推进成功版本，能够受控恢复；包括后端内容回到历史成功 revision 的情况。

第一阶段不要求 Web 编辑任务、Focus Mode、自动提醒执行或物理按键。若用户希望首轮加入这些功能，先报告对五周计划和接口的影响，再共同确认。
