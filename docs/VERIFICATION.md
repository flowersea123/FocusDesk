### ChatGPT 浏览器扩展

下载 ZIP 中的五个文件与扩展源码逐字节一致。使用临时 Chrome 配置打开本地构造的聊天页面，执行 ZIP 中原样的内容脚本，并用受控的消息通道核对生成开始和结束。脚本取得了示例提问和可见的最终回答，跳过隐藏文字、工具内容和推理区；停止记录后的新提问没有写入。此测试没有登录 ChatGPT，未覆盖从已侧载的原生扩展后台到真实网站的整条链路。Hub 接收端另由接口用例覆盖。

## 固件与设备

- 两个平台均通过 **1,149 个 C++ 主机检查**，覆盖快照、配网解析、配置事务、会话、Hub 响应校验及设备同步。31 个 400 × 300 场景与对应画面逐像素一致，每个平台比对 3,720,000 个像素。
- 在 macOS 上用 Arduino CLI 1.5.1、Arduino-ESP32 Core 3.3.12、Xtensa GCC 14.2.0、Adafruit GFX 1.13.0、BusIO 1.17.4，以示例配置完整编译、链接正式 `focusdesk_device`。通用 ESP32-S3 编译配置下，程序占 **1,002,349 / 1,310,720 B**，静态 RAM 占 **83,004 / 327,680 B**。同时运行了旧版静态显示、联网 sketch 和驱动预览测试。
- 本轮没有操作串口、烧录设备或触发实体屏刷新。实际板卡的配置、手机入网、断电恢复、颜色和物理刷新效果需在匹配的硬件上复验。[正式固件入口](../firmware/focusdesk_device/README.md)

## 上传前的仓库检查

- 保留源码、依赖锁文件、设备及字体许可、合成样例和验证说明。只读扫描候选文件和当前分支可达历史，检查常见私钥、服务令牌、带凭据地址、个人绝对路径及敏感文件名。疑似值逐项复核为测试样例或程序变量；仓库中的扩展密钥字段是公开标识。检查范围不包含远端的其他分支。
- 逐张检查跟踪的示例图片，核对扩展下载 ZIP 和扩展目录。真实任务、屏幕记录、Outlook 状态、模型权重、私有设备配置及构建产物不随源码交付。Git 工作目录里的本地缓存与 Git 将上传的文件范围不同。
- 安装器和 LAN 便携导出均已增加对 Python 字节码、开发缓存及私有邮件或密钥文件的过滤，并用包含这些文件的测试目录验证。另外在 Linux 使用干净的源码目录和含字节码、私有测试头文件的目录各导出一次。两个便携包的 68 个相对路径和文件哈希逐一一致，随包任务取自公开样例。
- 本版尚缺 Windows 原生安装、升级、卸载、托盘、异常进程回收和桌面截取的当次实机记录。Linux 软件回归在无桌面容器完成，真实 X11 前台采集需有相应会话与权限。仓库中的 Git 提交会保留作者元数据。

## 如何重跑

按[根 README](../README.md)安装两个子项目依赖后运行 `npm run verify`。只重跑一个范围时，可以使用 `package.json` 里的命令，如 `npm run test:frontend` 或 `npm run test:provisioning`。HTTP 集成和桌面测试需先构建网页。Windows 下载和准备对应桌面运行时后，可按[安装器说明](../installer/README.md)在隔离用户目录设置 `FOCUSDESK_RUN_INSTALLER_E2E=1`，再运行 `npm run test:installer`，另外验证安装、升级和卸载。

准备好本机模型之后，以下命令可再次评分两套邮件样例。输出目录应先存在，结果文件留在本机。

```sh
node experiments/mail-ai/evaluation/run.mjs .cache/mail-qa-first.json
node experiments/mail-ai/evaluation/run.mjs .cache/mail-qa-second.json second
```
