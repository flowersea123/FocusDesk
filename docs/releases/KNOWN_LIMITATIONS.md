# FocusDesk M2 已知限制

记录日期为 2026-11-07。当前版本用于受控试用，Windows 安装包及统一设备固件沿用本轮冻结产物。

## 验证范围

- 用户于 2026-11-07 人工确认 H1–H6 真机测试通过。人工测试与自动化软件回归分别记录，详见 [M2 发布记录](M2_RELEASE.md)。
- H7 长时间稳定性测试暂缓，未执行。当前证据覆盖已完成的测试场景，生产级长期稳定性仍待后续验证。
- 本轮发布整理核对既有产物和证据。干净 Windows 虚拟机、更多独立电脑以及更多路由器/手机组合尚未完成新一轮覆盖。
- 既有安装升级卸载自动验收来自项目测试环境。当前 Windows 安装程序尚未代码签名，Windows SmartScreen 可能显示发布者提示。

## 热点凭证与固件交付

设备配置热点采用 WPA2 密码保护。热点连接卡属于单独提供的设备交付资料，真实密码与公开试用包分开保管。

当前冻结的固件镜像内置测试热点凭证，具备提取条件的人可以从二进制中取得该凭证。同一个镜像刷到多台设备时，这些设备会使用相同的热点密钥。连接卡用于交付登录信息，设备实际使用的密钥由所刷入的镜像决定。

用户已确认采用预刷设备试用模式。公开试用包提供安装程序、文档和脱敏源码，现有 BIN 按已批准模式从公开包中排除。逐台生成独立密钥仍需专门的预刷和交付流程。对应源码、预刷前提与许可要求见 [固件预刷说明](FIRMWARE_UPLOAD.md) 和 [第三方声明](THIRD_PARTY_NOTICES.md)。

使用过的设备可能仍在 NVS 中保留上一位用户的 Wi-Fi 记录和 Hub 地址。交付负责人需通过独立设备准备流程检查并处理旧记录，或使用全新设备。本次发布仅整理交付物，设备准备和预刷另行执行。

## 网络与配置

- Hub 地址使用 HTTP IPv4，由用户在手机页面手动填写。设备自动发现、自动配对和账户系统留待后续阶段。
- 电脑与 ESP32 需要局域网互访。来宾网络、AP 隔离、企业策略和 Windows 防火墙规则可能阻止通信，托盘网络诊断仅提供只读提示。
- 保存新配置时，目标 Wi-Fi 和 FocusDesk Hub 都需要可达。页面出现设备 IP 后，Hub 验证和保存过程可能仍在继续。
- Wi-Fi 适配个人 WPA2 兼容的 2.4GHz 网络。SSID 为 1–32 个 UTF-8 字节，密码为 8–63 个可打印 ASCII 字符。开放网、企业认证和64字符原始十六进制 PSK 超出当前支持范围，WPA3-only 网络兼容性尚待实测。
- 每次启动提供 10 分钟配置热点窗口，RST 重新打开。AP+STA 共用射频，连接路由器时的信道切换可能暂时断开手机。
- 设备热点使用 `192.168.4.0/24`。路由器网络使用同一网段时可能冲突，当前版本会拒绝这种候选配置，需使用其他局域网网段。
- 普通 NVS 保存 Wi-Fi 密码和 Hub 配置，当前采用明文存储。Flash 擦除、分区表变化或 Core 对损坏/不兼容默认 NVS 分区的恢复可能清除配置。
- 写入接口可能在数据已落盘后返回错误。设备会重新读取实际已发布记录，恢复旧配置或已经完成验证的新配置，页面保留保存错误提示。

## 显示、任务和专注

- 设备正常约 30 秒轮询一次，相邻刷新至少间隔 60 秒。电子纸全刷和网络重试还会增加等待时间，保存后通常留出约 1–2 分钟观察。
- 全刷继续使用同步显示驱动，主循环中的配置或重连处理可能暂时排队，刷新完成后继续处理。
- Dashboard 保存成功表示 Hub 接收并保存了数据，当前没有电子纸同步回执。设备断网、电脑退出应用、睡眠或关机时，屏幕可能保留旧任务或已经到期的专注画面。
- 当前最多三条任务，标题为 1–40 个可打印 ASCII 字符。中文任务标题仍待后续字体与渲染支持。
- 任务日期和时区沿用现有数据。当前没有按实际日期自动生成或筛选每日任务的逻辑，导入的演示日期也会保留。
- Focus Mode 为固定 25 分钟，结束和恢复由 Hub 及后续成功同步驱动。设备显示结束时间，实际页面切换受轮询和刷新保护影响。
- 当前设备与经过验证的接线组合完成本轮人工测试。其他 ESP32-S3 板型、Flash/PSRAM 配置和面板组合仍需单独验证。

## Windows 运行与数据

Dashboard帮助区域保留了开发版 `backend/data/tasks.json` 路径提示。安装版用户通过页面编辑任务，实际数据位于 `%LOCALAPPDATA%\FocusDesk\data\tasks.json`。本发布指南采用安装版数据位置。

应用通过当前 Windows 用户的托盘进程运行。关闭浏览器后后台继续服务，托盘退出、用户会话结束或电脑睡眠/关机会中断同步。当前版本按用户手动启动，开机自启和系统服务尚待后续实现。

本机 Dashboard 可编辑，其他局域网客户端保持只读。任务存储沿用 JSON、原子保存和版本冲突保护。导入会替换整份任务文件并先备份，自动合并多份任务仍待后续实现。默认卸载保留 `%LOCALAPPDATA%\FocusDesk` 中的数据，用户手动删除文件或磁盘故障仍可能造成数据丢失。

安装包包含 Node.js 24.16.0 Windows x64 运行时。普通用户使用说明见 [用户指南](USER_GUIDE.md)，工程构建和预刷操作由交付负责人按对应说明执行。
