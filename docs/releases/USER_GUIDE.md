# FocusDesk M2 试用用户指南

适用于 Windows 10/11 x64 电脑和已预刷统一固件的 ESP32-S3 电子纸设备。

## 首次使用前

本试用包采用已确认的预刷设备模式，提供 `FocusDesk-Setup.exe`、说明文档和脱敏源码。现有固件二进制按该模式从公开包中排除，由交付负责人在受控预刷流程中管理。

请另行取得预刷好的设备和随设备单独提供的热点连接卡，并准备一部可以连接 Wi-Fi 的手机。连接卡属于独立设备交付资料，真实密码单独交付并与设备配套保管。设备准备、预刷和分发要求见 [固件预刷说明](FIRMWARE_UPLOAD.md)。

使用过的设备可能保留先前的 Wi-Fi 记录和 Hub 地址。交付负责人在独立设备准备流程中检查并处理这些旧记录，或使用全新设备。本次发布整理交付物，设备准备另行执行。

电脑与设备需要接入可以互相访问的同一路由器网络。设备使用 2.4GHz 个人 Wi-Fi，电脑可使用该路由器的网线、2.4GHz 或 5GHz 网络。

## 1. 安装并打开电脑应用

1. 运行 `FocusDesk-Setup.exe`，按安装向导完成安装。
2. 从桌面或开始菜单打开 FocusDesk，默认浏览器会自动打开 Dashboard。
3. 在 Windows 通知区域找到 FocusDesk 图标，右键选择“设备连接”。图标可能收在通知区域的展开菜单中。
4. 复制当前电脑设备连接页面提供的 ESP32 API 地址。后面手机填写的 Hub 与当前编辑 Dashboard 的电脑应是同一台。

安装包内置固定 Node.js 24.16.0 运行时。日常使用通过快捷方式、浏览器和托盘菜单完成。

## 2. 手机为设备配置网络

1. 通过 USB 给设备通电。每次启动后的配置窗口持续 10 分钟。
2. 手机连接 `FocusDesk-Setup-XXXXXX` 热点，密码使用配套连接卡上的内容。手机提示该热点没有互联网时，选择保持连接。
3. 在手机浏览器打开 `http://192.168.4.1`。
4. 在 `Wi-Fi name` 填写家里或当前路由器的 2.4GHz Wi-Fi 名称，在 `Wi-Fi password` 填写这个 Wi-Fi 的密码。
5. 在 `Hub address` 粘贴电脑设备连接页面提供的 ESP32 API 地址。设备使用电脑的局域网 IPv4 地址，`127.0.0.1` 只供电脑本机打开 Dashboard。
6. 点击 `Save and connect`，等待页面明确显示 `settings were saved`。保存前设备会验证 Wi-Fi 和正在运行的 FocusDesk Hub，单独出现设备 IP 时可能仍在验证。

连接路由器时，手机可能暂时离开设备热点。重新加入同一热点并打开上述页面，页面会继续查询结果。热点窗口结束后，按设备 RST，再重新连接热点和打开页面。

## 3. 编辑任务和使用专注

在电脑本机 Dashboard 点击“编辑任务”，添加、修改、勾选完成或移除任务，再点击“保存更改”。当前最多三条任务，标题使用 1–40 个可打印 ASCII 字符，例如英文、数字和常见英文标点。保存后列表会更新。

设备正常每 30 秒读取一次任务，相邻电子纸刷新至少间隔 60 秒。保存后请留出约 1–2 分钟观察屏幕全刷，网络重试时可能更久。相同内容保持显示。

在 Focus Mode 选择一条未完成任务，点击“开始专注 · 25 分钟”。电子纸会在下一次允许的同步中显示专注任务和结束时间。点击“结束专注”或专注到期后，设备在后续成功同步中恢复总览。任务完成状态由用户管理。

电脑网页保存成功表示 Hub 已保存数据，实际屏幕结果请直接观察电子纸。

## 日常开关与重新配置

- 每次使用时打开电脑上的 FocusDesk，再给设备通电。设备会读取已保存的 Wi-Fi 和 Hub 配置并恢复连接。
- 关闭 Dashboard 浏览器窗口后，托盘应用继续运行，设备继续同步。可从托盘“打开 Dashboard”重新进入。
- 托盘“退出 FocusDesk”会停止本实例的后台服务。电脑睡眠、关机或网络中断期间，设备会保留最后一次有效画面，电脑恢复运行后再同步最新数据。
- 换 Wi-Fi、换电脑或电脑 IP/端口变化后，先在目标电脑打开 FocusDesk 并复制设备连接页面的新地址，再按设备 RST，重新填写完整 Wi-Fi 与 Hub 配置并保存。
- 新 Wi-Fi 或 Hub 验证失败时，设备保留并尝试恢复原有效配置。配置窗口关闭后，设备继续按原配置连接并读取任务。

## 升级、卸载和旧数据导入

任务、活动专注、配置、日志和备份保存在 `%LOCALAPPDATA%\FocusDesk`，与程序安装目录分开。保存采用版本检查与原子替换。升级只更新程序文件，默认卸载保留用户数据，重新安装后可以继续读取。

页面帮助中出现的 `backend/data/tasks.json` 属于开发版提示，安装版的任务文件位于 `%LOCALAPPDATA%\FocusDesk\data\tasks.json`，日常任务操作在Dashboard完成。

从旧版 FocusDesk-LAN 迁移时，先退出旧服务，在新应用托盘选择“导入旧任务…”，选取旧版任务文件。程序先校验文件，再请求确认替换，并备份当前数据。导入替换整份任务与专注数据，任务 ID、顺序、状态、日期和时区按原格式保留。

## 常见问题

| 现象 | 操作 |
| --- | --- |
| 手机找不到设备热点 | 确认 USB 供电，按一次 RST，在 10 分钟窗口内重新查找 |
| 手机网页打不开 | 确认手机连接设备热点并保持连接，浏览器使用完整 `http://192.168.4.1` |
| Wi-Fi 已连接，Hub 验证失败 | 确认电脑应用正在运行、地址来自这台电脑的设备连接页，并检查同一路由器网络的设备互访 |
| Windows 提示网络访问 | 按实际使用环境允许 FocusDesk 内置运行时访问专用网络，也可在托盘选择“检查专用网络访问”查看诊断 |
| 保存任务后屏幕暂时没变 | 等待约 1–2 分钟，确认本机 Dashboard 与设备指向同一台 Hub，检查电脑应用和网络仍可用 |
| 修改任务出现版本冲突 | 保留需要的草稿内容，按网页提示核对最新任务，再重新编辑保存 |
| 启动提示端口或数据已使用 | 检查旧版 FocusDesk 是否仍在运行，退出旧实例后重试，并从托盘“打开日志目录”查看记录 |

当前发布的验证范围、长时间测试状态和凭证分发限制见 [已知限制](KNOWN_LIMITATIONS.md)，完整证据见 [M2 发布记录](M2_RELEASE.md)。
