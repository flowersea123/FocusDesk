# FocusDesk M2-RC1 快速开始

本包用于已预刷统一固件的设备。先向交付负责人取得对应设备和单独提供的热点连接卡。

1. 电脑运行 `FocusDesk-Setup.exe` 完成安装，从桌面打开FocusDesk。
2. 在Windows通知区域右键FocusDesk图标，打开“设备连接”，复制当前电脑提供的ESP32 API地址。
3. 设备通过USB通电。手机连接 `FocusDesk-Setup-XXXXXX` 热点，使用设备配套连接信息，在浏览器打开 `http://192.168.4.1`。
4. 填写路由器的2.4GHz Wi-Fi名称、密码和上一步复制的Hub地址，点击 `Save and connect`，等待出现 `settings were saved`。
5. 在这台电脑的Dashboard编辑并保存任务，等待约1–2分钟观察电子纸更新。当前最多三条任务，标题使用1–40个英文ASCII可打印字符。

日常使用时打开电脑应用并给设备通电，设备会恢复已保存的配置。关闭浏览器后托盘应用继续运行。换网络或电脑地址时，按设备RST重新打开10分钟配置窗口并填写完整配置。

手机暂时掉线时重新加入设备热点并打开同一页面。热点关闭后按RST重新进入。电脑、ESP32和路由器需要保持局域网可达，保存配置时电脑应用应正在运行。

本批H1–H6由用户于2026-11-07人工确认通过，H7内存与长期稳定性暂缓。程序采用未签名的现有安装包，来源及哈希见 [版本清单](M2_RELEASE_MANIFEST.md)。

完整操作见 [用户指南](USER_GUIDE.md)，已知边界见 [限制说明](KNOWN_LIMITATIONS.md)。本公共包提供安装程序、文档和脱敏源码，固件二进制由交付负责人留存，热点连接信息单独提供。
