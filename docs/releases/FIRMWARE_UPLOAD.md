# FocusDesk M2 RC1 固件维护与上传说明

本文面向负责预刷或维护设备的开发者。普通试用者取得预刷设备后使用USB供电，在电脑安装FocusDesk，并按首次配网说明连接设备。

本批公开试用包仅包含Windows安装包、文档和脱敏项目源码。当前固件BIN、ELF、MAP、热点连接卡和真实私有头文件由维护者本地保管，以下镜像参数用于维护审计及后续经过授权的工程操作。

## 当前固定工件

当前统一入口为 `firmware/focusdesk_device/focusdesk_device.ino`。P3最终构建manifest对应Core3.3.12、`esp32:esp32:esp32s3`、4MB/default配置，应用镜像SHA-256为下列值。

```text
7837d38fbb231c3c211fe08d42816222298f3ed2bc2b7ba0b94f2030c8f564d4
```

本地应用镜像大小为987,808字节。

该应用镜像内含构建时生成的实验热点凭据。凭据和镜像的分发范围由发布者确认，连接信息经设备连接卡单独交付。维护者应按照本批交付清单核对文件与哈希，并使用相同硬件设置。

本批保留既有Windows安装包0.1.0和P3固件工件，M2 RC1是交付批次标识。文档整理本身不产生新固件版本。

## Arduino IDE 手动上传

1. 打开完整对应源树中的 `firmware/focusdesk_device/focusdesk_device.ino`。
2. 使用Arduino-ESP32 Core3.3.12、Adafruit GFX1.13.0及BusIO1.17.4。Core Debug Level设为None。
3. 沿用该板此前成功的板卡、端口、USB、Flash、分区及PSRAM设置。当前工件的4MB通用配置依据构建清单，实际板卡差异需在重建时对应。
4. 保留原有NVS时，确认Erase All Flash Before Sketch Upload为Disabled，并保持分区布局一致。
5. 维护者执行验证和上传。本文编写和发布整理期间未进行烧录、擦除或串口操作。
6. 普通上传后，原P2/P3保存的有效配置会从同一 `focusdesk_p2` 命名空间恢复。按RST可以重新打开10分钟设备配置窗口。

首次从公开源码重建时，由维护者运行 `scripts/prepare-provisioning-poc.mjs` 生成自己的实验热点密钥。项目的配置样例和生成器属于对应源码材料。

## 交付设备上的个人配置

维护者交付前应按单独授权的设备准备流程，使用全新或已清理个人配置的设备。当前NVS使用双槽，前一轮有效配置可能仍保留在旧槽中，包含此前的Wi-Fi名称、密码和Hub地址。设备准备流程应覆盖完整个人配置，而页面改为新网络只会完成一次正常配置更新。本次发布整理没有执行设备擦除或清理操作。

## 本批镜像偏移与NVS范围

下表直接依据本批构建输出的 `flash_args`、`partitions.csv` 和展开构建属性记录。

| 内容 | 写入偏移或范围 | 用途 |
| --- | --- | --- |
| `focusdesk_device.ino.bootloader.bin` | `0x0000` | ESP32-S3 bootloader |
| `focusdesk_device.ino.partitions.bin` | `0x8000` | 当前default分区表 |
| 已有NVS | `0x9000`至`0xDFFF`，大小`0x5000` | 用户Wi-Fi/Hub配置等持久数据 |
| `boot_app0.bin` | `0xE000` | OTA启动选择初始化数据 |
| `focusdesk_device.ino.bin` | `0x10000` | app0应用镜像，分区大小`0x140000` |
| app1 | `0x150000` | 另一OTA应用分区 |

本批展开参数记录flash mode为dio、频率80MHz、容量4MB，内存类型字段为qio_qspi。应按工件的实际参数解释，字段名称不能据此替代对实物板卡的确认。

应用 `.bin` 仅包含应用分区映像，用户NVS记录在独立分区。维护者确认设备已有匹配bootloader/分区表、应用从app0启动后，可以将应用镜像单独写入 `0x10000`。使用其他OTA活动槽或其他分区布局时，先按实际启动信息制定对应维护步骤。

首次预刷所需bootloader、分区表、OTA初始化和应用应按上述分离工件及实际板卡设置处理。4MB merged镜像会覆盖更大地址范围，其填充区可能覆盖已有NVS；本批维护交付采用分离工件及明确偏移。分区表变更、整片擦除及Core对特定损坏分区的默认恢复也可能清除已保存配置。

## 上传后的使用与检查

1. 电脑启动FocusDesk，通过设备连接页取得同一局域网可达的Hub地址。
2. 设备通电。已有有效NVS配置时自动连接；新设备由手机连接 `FocusDesk-Setup-XXXXXX` 热点并打开 `http://192.168.4.1`。
3. 手机输入路由器2.4GHz Wi-Fi名称、密码和Hub地址，等待页面明确显示配置已保存。
4. Dashboard保存任务修改后等待电子纸同步。成功轮询间隔约30秒，相邻刷新至少60秒，包含全刷时可留出约1–2分钟观察。
5. 核对专注开始、退出和断电恢复；热点窗口结束后Hub轮询继续，RST重新打开配置窗口。

用户于2026-11-07人工确认H1至H6通过，H7暂缓。发布整理中的哈希、许可材料和文件完整性检查属于电脑端证据，真机结论取自上述用户反馈。本次维护说明没有新增设备上传或硬件验收记录。
