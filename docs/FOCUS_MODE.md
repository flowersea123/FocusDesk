# 最小 Focus Mode

已实现固定 25 分钟专注；复用现有本地 Backend、原子任务文件和统一读取接口，不增加服务、数据库或计时依赖。保持英文任务和设备页面。

## 更新并运行

1. 在原服务窗口按 Ctrl+C 停止旧版本。在 PowerShell 中执行：

   ```powershell
   cd E:\FocusDesk
   npm run build
   npm run demo
   ```

2. 在电脑本机打开或刷新 `http://127.0.0.1:8787/`。今日任务下出现 Focus Mode，可选一条已保存的未完成任务，然后点击“开始专注 · 25 分钟”。电脑局域网 IP 页面和 Mock 开发模式仍只读。
3. Arduino IDE 关闭后重新打开 `E:\FocusDesk\firmware\focusdesk_live\focusdesk_live.ino`，沿用原私有配置和板卡/端口，先验证，再由用户上传。旧固件可继续显示任务，但不会显示专注页；Agent 未操作上传或串口。
4. 等待设备轮询与刷新保护允许后显示 Focus mode、所选任务及本地结束日期/时间。结束时间基于服务电脑时钟，显示时区为任务数据里的 Asia/Shanghai 或 UTC；与任务文件的演示日期分开。

## 手动验收

- 选择第二条未完成任务开始专注，检查网页与电子纸显示同一个任务和结束时间，过程中无需按 Reset。
- 保持专注不变，设备轮询不应反复全刷；页面不是秒级倒计时。
- 点击“结束专注”，下次同步后两端恢复总览，任务仍为未完成。之后可重新开始。
- 再开始一次并等待 25 分钟；服务在到期后的读取中发布 focus:null，两端在下次成功轮询后恢复总览。现有约 30 秒轮询和 60 秒刷新保护仍有效，因此不承诺到秒切换。
- 专注中编辑任务标题，专注保留且标题同步；完成或移除专注任务，保存后退出专注。不自动修改任务完成状态。
- 刷新网页或重启服务，未到期专注仍可恢复。断网时电子纸可能保留到期画面，联网后按最新快照恢复；读取成功不是设备回执。

## 数据和边界

`PUT /api/v1/daily-overview/focus` 接受 revision 和 start/stop，固定时长由服务生成，前端不能写入自定义结束时间。focus 与 tasks 在同一个原子文件中存储，共享队列和版本保护。并发/过期版本返回 409，不自动重试写入；任务草稿继续保留，需按提示核对最新内容。

活动状态保存在原任务文件的可选 focus 中，旧文件无需迁移或手动补字段。到期判断只影响读取响应和 revision，不每秒写文件；下次实际保存会移除旧记录。系统时钟需正常；没有设备本地计时、暂停、时长自选、番茄统计、历史记录、提示音或自动完成。

自动测试使用临时任务文件和可控服务时钟，不修改用户数据，不必等待真实 25 分钟。真机显示及真实等待仍由用户验收。
