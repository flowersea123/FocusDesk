# 网页任务编辑

当前继续英文任务，最多三项。读取模型和固件不变，不需要重新烧录。

## 使用步骤

1. 在原服务终端按 Ctrl+C，回到 `E:\FocusDesk` 后执行 `npm run demo`。当前前端产物已构建，源码后续修改时先执行 `npm run build`。
2. 在同一电脑打开或刷新 `http://127.0.0.1:8787/`。编辑仅限本机同源页面；电脑局域网 IP 打开的页面仍可读取。ESP32 继续使用电脑局域网 IP。
3. 点击“编辑任务”。修改英文标题，勾选/取消完成；“添加任务”产生新 ID。最多三条，达到上限可先移除草稿中的已有任务。
4. 编辑只改变草稿，预览仍代表已保存内容。点击“保存更改”才提交，移除也只在保存后生效；“取消编辑”放弃草稿，不修改任务文件。
5. 保存成功后列表和预览立即显示服务返回的数据；设备在原有轮询/刷新间隔后读取。没有设备回执，不把网页保存成功当作屏幕已同步。

标题需为 1–40 个可打印 ASCII 字符，不能全为空格。原有 ID、截止时间等字段在编辑标题/完成状态时保留；新任务默认 todo、due_at 为 null。网页不改 date/timezone，不自动删除已完成任务；保存空列表表示明确清空任务。

## 保存失败与冲突

保存期间禁用重复提交；失败保留草稿和上次有效数据，不自动重试写入。网络中断时不能仅凭失败提示判断服务是否收到写入，可以先读取并核对。

其他窗口或手动文件编辑已经改动任务时，旧版本保存返回 409。界面保留草稿并尝试读取最新数据，暂停再次保存；“放弃草稿，载入最新任务”会明确放弃当前草稿，再基于已读取数据编辑，不静默覆盖其他更新。

服务串行比较版本，校验完整输出和文件大小，再写同目录临时文件并原子替换。失败不先删旧文件；等价保存不重写、不变版本。重启后仍读取已保存文件。与外部文件编辑器没有跨进程锁，建议一次使用一个写入入口。
